# Signal Drop Splitter

Splits a csv file generated by rtl_power into two parts, separated by the point of largest drop in overall
signal strength. For use with the RTL-SDR.

I don't know if this is a common problem but for me sometimes when using the RTL-SDR with rtl_power the
readings returned drop significantly in strength and stay that way until rtl_power is restarted. This
program searches for the point in time of this event, and splits the csv file into a part1.csv and part2.csv,
where part1.csv contains all data before the event and part2.csv contains all data immediately after it.

## Usage:

```
signal_splitter input.csv output_part1.csv output_part2.csv
```
